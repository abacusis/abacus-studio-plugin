# Abacus Studio for Codex

Version 0.32.1.

Build your software with AI, without doing it alone. Abacus Studio brings engineering playbooks, curated project decisions, optional mockups, security guidance and reviewed submission to your Codex workflow.

Small changes stay focused. Substantial changes can use eight specialist profiles installed locally during approved Setup. Named profiles use Codex native delegation; trusted lifecycle hooks connect their recorded activity to the local dashboard. Existing profiles and global settings are preserved. See TESTING.md for executed checks and remaining live acceptance.

See [Installation and testing](INSTALL.md). No automatic commits, pushes, merges or deployments. Readiness is not Abacus approval.
